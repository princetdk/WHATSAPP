# SMS + WhatsApp Bot Application

A comprehensive application for receiving SMS via temporary phone numbers and managing a WhatsApp bot.

## Features

- Receive SMS via temporary phone numbers
- WhatsApp bot integration
- SMS monitoring dashboard
- Real-time notifications
- Multi-language support (French, English)

## Tech Stack

- Backend: Node.js/Express
- Frontend: React
- Database: MongoDB
- APIs: Twilio (SMS), WhatsApp Business API

## Project Structure

```
.
├── backend/           # Express API server
├── frontend/          # React dashboard
├── config/            # Configuration files
├── docs/              # Documentation
└── tests/             # Test files
```
